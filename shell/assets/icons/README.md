Symbolic icons from the [Adwaita icon theme](https://gitlab.gnome.org/GNOME/adwaita-icon-theme)
(GNOME Project, CC BY-SA 3.0 / LGPL-3.0), renamed to the names the shell uses.
They match the icons of GTK and the vela settings, whatever icon theme is set.

`share`, `laptop`, `devices` and `upload` (Adwaita's `folder-download` with the
arrow turned up) are drawn for vela in the same style.
